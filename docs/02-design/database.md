# Структура базы данных

## Таблица «Тип оборудования»

- Код типа
- Наименование типа (компьютер, ноутбук, монитор, принтер, сетевое оборудование)

## Таблица «Подразделения»

- Код подразделения
- Наименование подразделения

## Таблица «Сотрудники»

- Табельный номер
- Фамилия, имя, отчество
- Должность
- Код подразделения

## Таблица «Оборудование»

- Инвентарный номер
- Код типа
- Модель
- Серийный номер
- Дата поступления
- Стоимость
- Место установки (номер кабинета)
- Табельный номер ответственного сотрудника
- Состояние (в эксплуатации, в ремонте, списано)

## Таблица «Перемещения»

- Номер перемещения
- Инвентарный номер
- Дата перемещения
- Прежнее место установки
- Новое место установки
- Прежний ответственный сотрудник
- Новый ответственный сотрудник

## Таблица «Ремонты»

- Номер ремонта
- Инвентарный номер
- Дата передачи в ремонт
- Описание неисправности
- Дата окончания ремонта
- Результат ремонта

## Таблица «Списание»

- Номер акта списания
- Инвентарный номер
- Дата списания
- Причина списания

## Связи между таблицами

1. Один тип оборудования соответствует многим единицам оборудования.
2. Одно подразделение включает многих сотрудников.
3. Один сотрудник может отвечать за многие единицы оборудования.
4. Одна единица оборудования может иметь много перемещений и ремонтов.
5. Одна единица оборудования может иметь не больше одного акта списания.
