# Порядок установки программы

## Требования к компьютеру

1. Операционная система Windows 10 или новее.
2. Установленный интерпретатор Python версии 3.10 или новее.
3. Не менее 100 МБ свободного места на диске.

## Установка

1. Скачать проект с GitHub командой git clone или кнопкой Code, затем Download ZIP.
2. Распаковать архив в папку на компьютере.
3. Открыть командную строку в папке src.
4. Выполнить команду python main.py.

## Обучение пользователей

1. Провести инструктаж сотрудников ИТ-отдела по работе с реестром.
2. Передать материально ответственным лицам руководство пользователя.
