# Требования к программе учета компьютерной техники

## Цель создания программы

Автоматизация учета компьютерной техники организации для сокращения времени
инвентаризации и повышения достоверности сведений о технике.

## Функциональные требования

1. Ведение реестра оборудования с указанием инвентарного номера, типа, модели,
   серийного номера, даты поступления, стоимости, места установки и ответственного сотрудника.
2. Закрепление оборудования за сотрудниками и кабинетами.
3. Учет перемещений оборудования между кабинетами и сотрудниками.
4. Учет ремонтов с указанием даты, причины неисправности и результата ремонта.
5. Оформление списания оборудования.
6. Поиск оборудования по инвентарному номеру, типу и ответственному сотруднику.
7. Формирование отчетов для инвентаризации.
8. Выгрузка отчетов в формат Excel.

## Категории пользователей

1. Администратор системы.
2. Сотрудник ИТ-отдела.
3. Материально ответственное лицо.
4. Сотрудник бухгалтерии.
5. Руководитель организации.

## Нефункциональные требования

1. Программа работает в операционной системе Windows 10 и новее.
2. Интерфейс программы на русском языке.
3. Время поиска записи в реестре не превышает 2 секунд.
4. Доступ к функциям программы разграничивается по категориям пользователей.
