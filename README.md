# Программа учета компьютерной техники в организации

Учебный проект по дисциплине «Проектная деятельность в ИТ».
Программа предназначена для ведения единого реестра компьютерной техники организации,
учета ее перемещений, ремонтов и списания.

## Структура проекта

- docs/01-analysis — материалы этапа анализа требований
- docs/02-design — материалы этапа проектирования
- src — исходный код программы
- tests — материалы этапа тестирования
- docs/05-deployment — материалы этапа внедрения
- docs/06-maintenance — материалы этапа сопровождения

## Ветки репозитория

- main — основная ветка, содержит проверенную версию проекта
- develop — ветка разработки, в нее сливаются результаты этапов
- stage/01-analysis — этап анализа
- stage/02-design — этап проектирования
- stage/03-development — этап разработки
- stage/04-testing — этап тестирования
- stage/05-deployment — этап внедрения
- stage/06-maintenance — этап сопровождения
